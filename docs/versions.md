# Versions & history

This is the working documentation for the OpenPowerBox reference prototype. It brings the owner's installation and operating guide together with the design explanation, a first cost review, and clearly identified performance estimates.

## Current documentation · November 2026

| Area | What is available | What remains |
|:---|:---|:---|
| System design | Reference components, energy balance, and scaling concepts | Validated alternative configurations |
| Build | Assembly overview and reviewed mounting procedure | Final aluminum drawings, exact parts, and as-built wiring/protection schedule |
| Operation | Startup, normal use, shutdown, storage, troubleshooting, and maintenance from the reviewed manual | Updates as the hardware changes |
| Cost | Current retail examples and explicit small-parts allowances | Reconciled as-built purchases and exact quantities |
| Testing | Team-reported runtime and the method for documenting results | Original measurement record, complete conditions, and outdoor field results |

The practical and visual homepages are two introductions to **the same guide**, not two hardware versions.

## Prototype revisions and hardware releases

Older project files describe a wood mount and earlier controller or output choices. The reviewed manual describes an aluminum support and SmartSolar 75/15. This site follows that manual for the current reference configuration; the earlier CAD is labeled where used.

No complete v1.0 hardware package has been released. A release should keep compatible parts, fabrication drawings, wiring and protection, settings, operating instructions, and test evidence together. Prototype labels such as VP1 and VP2 in project files are not public release guarantees.

## Track a change

Use **View page history** at the bottom of a page to see its edits on GitHub. Use **Suggest an improvement** to identify unclear instructions, missing evidence, or a proposed change.

When a full design release is ready, the repository can provide a named snapshot with the source files, drawings, manual, test data, and a readable change summary. Record that release and any deviations with a completed build.
